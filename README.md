# fease-releases

Release assets downloaded by the FEASE macOS app (https://fease.app). This repository holds files and their notices only. It contains no source code.

The app pins every file here by size and SHA-256 and refuses any download that does not match, so a file in a release is never replaced. A changed file gets a new release tag.
